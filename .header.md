# Terraform STACKIT Redis module

> **⚠️ Deprecated.** STACKIT's Redis offering is deprecated — the `stackit_redis_*` resources will
> be removed after **August 2027**. For new workloads use
> [`terraform-stackit-valkey`](https://github.com/terraform-stackit-modules/terraform-stackit-valkey)
> instead (Valkey is the successor, same instance + credential shape). This module is kept for
> managing existing Redis instances during migration.

Terraform module which provisions a [STACKIT Redis](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/redis_instance) instance and its credentials on [STACKIT](https://www.stackit.de/en/).

This repository is not from the official STACKIT organization.

## Usage

```hcl
module "redis" {
  source  = "terraform-stackit-modules/redis/stackit"
  version = ">= 1.0.0"

  project_id    = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  name          = "app-redis"
  redis_version = "7.2"
  plan_name     = "stackit-redis-single-4"

  parameters = {
    sgw_acl          = "0.0.0.0/0"
    maxmemory_policy = "volatile-lru"
  }

  credentials = {
    app = {}
  }
}
```

See [`examples/basic`](./examples/basic) for a self-contained example (requires only `project_id`).

## Composite module

- `modules/instance` — the `stackit_redis_instance` (toggled by `create_instance`).
- `modules/credential` — `stackit_redis_credential` entries (`for_each` over `credentials`).

The root wires them together and, when `create_instance = false`, targets an existing instance via
`instance_id` for credential management.

## Notes

- Generated credentials (`password`, `uri`) are exposed via **sensitive** outputs.
- `credentials` is a map keyed by a **stable identifier**; the instance_id (known after apply when
  the instance is created here) is only a resource attribute, never a `for_each` key.
- Redis has no separate database/user resources in the provider — access is via credentials
  (auto-generated username/password), same shape as the MariaDB module.

## Terratest

The `test/` directory holds a Terratest integration test that applies the `examples/basic` root module against a real STACKIT project (requires `STACKIT_SERVICE_ACCOUNT_KEY` and `STACKIT_PROJECT_ID`).

```bash
cd test
go mod init github.com/terraform-stackit-modules/terraform-stackit-redis
go get github.com/gruntwork-io/terratest@v1.0.1
go mod tidy
go test -v -timeout 45m ./...
```
